# DAYFLOW PHP · 회원/관리자 연동

기존 일상관리시스템 화면을 CodeIgniter 4.7.4 + PHP 8.2 이상으로 연결했습니다. 개인 카페24 호스팅에서 사용하기 위한 버전입니다. 기존 Node PC 앱과 GitHub Pages 시연본은 저장소 상위 폴더와 docs에 유지됩니다.

## 기능

- 이메일/비밀번호 로그인, 로그아웃, 비밀번호 변경
- 관리자 회원 등록, 이용 중지/재활성화, 임시 비밀번호 재발급
- 첫 회원 로그인 및 재발급 후 비밀번호 변경 필수
- 관리자 공지 작성/수정/공개/비공개/삭제, 회원 대시보드 공지 표시
- 기존 일정·할 일·목표·루틴·가계부·자산·저축·예상수입·판매물품 기능
- 로그인 계정별 DB 저장. 관리자 API에도 타인의 개인 기록 조회 기능 없음
- JSON 백업/복원, 동시 수정 충돌 방지
- 비밀번호 해시 저장, 세션 재발급/중지 시 만료, CSRF 검사, 로그인 재시도 제한

회원은 관리자가 등록합니다. 공개 회원가입, 이메일 비밀번호 찾기, 은행 연동은 포함하지 않습니다. 관리자/서버 운영자가 DB 자체에 접근하면 저장된 기록을 열람할 수 있으므로, 앱의 접근 권한과 서버 관리 권한은 별개입니다.

## PC 실행

PHP 8.2 이상(intl, mbstring, mysqli), Composer, 개발용 MySQL/MariaDB가 필요합니다.

1. 이 php-server 폴더에서 `composer install` 실행.
2. `.env.example`을 `.env`로 복사하고 개발용 DB 정보 입력.
3. PC에서는 `CI_ENVIRONMENT = development`, `app.baseURL = 'http://localhost:8080/'`, `app.forceGlobalSecureRequests = false`, `cookie.secure = false`로 설정.
4. 빈 개발용 DB에 `php spark migrate --all` 실행.
5. `php spark dayflow:admin` 실행 후 첫 관리자 이메일/이름/비밀번호 입력. 기본 계정은 없습니다.
6. `php spark serve` 실행 후 http://localhost:8080 접속.
7. 관리자 로그인 → 관리자 화면에서 회원 등록 → 회원 로그인 → 비밀번호 변경.

최초 관리자 생성은 서버 명령줄에서만 가능합니다. 웹 설치 파일은 제공하지 않습니다. SSH가 불가능한 호스팅에서는 운영 DB 초기화/관리자 생성 절차를 별도로 준비해야 합니다.

## 검증

`node tests/dayflow-http.mjs`는 임시 SQLite DB와 임시 계정으로 실제 HTTP 요청을 검증합니다. PHP 경로가 다르면 환경변수 PHP_BIN을 설정합니다. 테스트 데이터는 종료 후 삭제합니다.

GitHub Actions는 별도 MariaDB 10.11 서비스로 같은 테스트를 실행합니다. 운영 DB를 지정하여 테스트하지 마세요. 테스트용 DB는 비어 있어야 합니다.

## 배포

저장소 루트의 `PHP-서버설치안내.md`를 읽으세요. GitHub Pages는 이 PHP 프로그램을 실행하지 않습니다. 코드의 GitHub 저장과 카페24 서버 배포는 별도 단계입니다.

실제 DB 정보, .env, 세션/로그, 사용자 데이터, 배포 압축 파일은 Git에 포함하지 않습니다. 사용자 자료의 주 저장소는 DB이며, 백업 JSON은 본인이 별도 다운로드할 수 있습니다. DB 자동 백업은 호스팅에서 별도로 설정해야 합니다.

개인 기록은 초기 구현의 호환성을 위해 사용자별 JSON 문서로 DB에 저장합니다. 대규모 통계/검색이 필요하면 항목별 테이블로 분리하는 확장이 필요합니다.
