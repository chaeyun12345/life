# DAYFLOW · 일상관리시스템

2차 메인 대시보드 디자인을 기준으로 만든 개인용 PC 앱입니다. 데이터는 실행한 PC의 파일에 저장됩니다.

## 실행

Node.js 22 이상이 필요합니다. 별도로 설치할 패키지는 없습니다.

```sh
npm start
```

브라우저에서 `http://127.0.0.1:4173`을 열어 사용하세요.

Windows에서는 `실행하기.cmd`를 더블클릭해 실행할 수 있습니다. 이 방식으로 실행한 앱은 `종료하기.cmd`로 종료합니다. 터미널에서 실행했다면 Ctrl+C로 종료하세요.

## 기능

- 메인 대시보드: 날짜형 주간 일정, 중요 소식, 할 일 체크, 통합 검색
- 일일·주간·월간 일정, 날짜별 루틴 및 메모
- 운동·독서·건강 등 생활 목표와 진행률
- 수입·지출·저축 이체 가계부, 월별 예산과 남은 생활비
- 보유 자산, 예상수입, 저축 목표 및 중고판매 물품 관리
- JSON 데이터 백업 및 복원

중요한 미완료 일정은 오늘부터 7일 이내에 소식창에 표시됩니다. 생활·저축 목표를 달성하면 목표 달성 소식이 표시됩니다. 예상수입을 입금 처리하거나 물품을 판매 완료로 저장하면 연결된 수입 거래가 중복 없이 가계부에 반영됩니다.

## 데이터

첫 실행 시 예시 데이터가 생성됩니다. 실제 사용을 시작할 때 앱에서 **예시 비우고 시작**을 선택하세요.

- 현재 데이터: `data/dayflow.json`
- 직전 저장 내용: `data/dayflow.previous.json`
- `data/`와 백업 파일은 Git에 포함하지 않습니다.
- 소스의 예시 데이터는 데모용입니다.
- 로그인, 은행 연동, 기기 간 동기화는 없습니다.
- 보유 금융 잔액은 직접 수정합니다. 가계부 거래가 자산 잔액을 자동 변경하지 않습니다.
- 정기수입은 분류이며, 매월 거래를 자동 생성하지 않습니다.

## 글꼴

Windows의 맑은 고딕을 우선 사용합니다. PC에서 복사한 `ui-font.ttf`는 저장소에 포함하지 않습니다. 글꼴이 없는 환경에서는 시스템 기본 글꼴로 표시됩니다.

## 검증

```sh
npm test
```

현금흐름, 수입과 판매의 중복 방지, 알림, 날짜 계산, 데이터 검증, 파일 저장·재실행 및 동시 저장 충돌을 확인합니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html`, `style.css` | 화면과 디자인 |
| `app.js` | 화면 동작, 입력, 검색, 백업 |
| `model.js` | 계산과 데이터 검증 |
| `server.js` | PC 내 데이터 저장 및 실행 |
| `launch.ps1`, `stop.ps1` | Windows 실행·종료 |
| `tests/` | 계산 및 저장 테스트 |
