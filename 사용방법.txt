DAYFLOW · 일상관리시스템
2차_메인대시보드 디자인을 기준으로 만든 PC 전용 앱입니다.

실행
1. 이 폴더를 원하는 위치에 보관하세요. C:\일상관리시스템\3차_코딩파일 로 옮겨도 됩니다.
2. 실행하기.cmd 를 더블클릭하세요.
3. 브라우저에 http://127.0.0.1:4173 이 열립니다.
4. 이 PC에서는 현재 설치된 Node.js를 사용합니다. 다른 PC에서는 Node.js LTS가 필요합니다.
5. index.html을 직접 열지 말고 실행하기.cmd로 실행하세요.
6. 종료하기.cmd를 실행하면 이 폴더의 앱을 종료합니다. 브라우저 창은 직접 닫아 주세요.

처음 시작
- 예시 데이터가 들어 있습니다. 먼저 사용해 보고 실제 기록을 시작할 때 '예시 비우고 시작'을 누르세요.
- 일정, 할 일, 목표 이름을 누르면 수정할 수 있습니다.
- 중요한 일정에 체크하면 오늘부터 7일 이내 일정이 소식창에 표시됩니다.
- 목표 수량을 달성하면 소식창에 목표 달성이 표시됩니다.
- 주간 날짜 버튼과 월간 달력에서 날짜를 바꿀 수 있습니다.
- 루틴 체크와 하루 메모는 날짜별로 저장됩니다.

돈 관리
- 남은 생활비 = 해당 월 수입 - 지출 - 저축 이체입니다.
- 예상수입은 '입금 처리'하거나 '입금 완료'로 저장하면 가계부에 한 번만 반영됩니다.
- 정기수입은 분류 표시이며 다음 달 거래를 자동 생성하지 않습니다.
- 저축 목표의 현재 금액 = 시작 잔액 + 목표에 연결한 저축 이체입니다.
- 물품을 판매 완료로 바꾸면 실제 판매가가 해당 판매일의 수입으로 기록됩니다.
- 현재 자산 잔액은 직접 입력합니다. 거래 입력이 금융 잔액을 자동 변경하지 않습니다.
- 저축 예상 시점은 이자와 투자수익 없이 다음 달부터 계획액을 더한 단순 예상입니다.

저장과 백업
- 모든 입력은 이 폴더 안 data\dayflow.json 파일에 저장됩니다.
- 저장할 때 이전 내용은 data\dayflow.previous.json에 보관됩니다.
- 인터넷이나 계정 없이 이 PC에서 사용할 수 있습니다. 다른 기기로 자동 동기화하지 않습니다.
- '데이터 백업'을 눌러 JSON 파일을 따로 보관하세요. '백업 복원'으로 다시 불러올 수 있습니다.
- 폴더를 옮길 때는 데이터 백업을 먼저 받고 실행 중인 앱을 종료한 뒤 data 폴더도 함께 옮기세요.
- PC를 재시작하면 실행하기.cmd를 다시 실행하세요.

소스 파일
index.html : 기본 화면
style.css : 2차 디자인과 작은 화면 대응
app.js : 화면, 입력, 검색, 체크, 목표와 백업
model.js : 현금흐름, 자산, 저축 계산과 데이터 검증
server.js : 내 PC 데이터 저장과 앱 실행
tests : 계산과 저장 검증
